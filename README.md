# Мой ВСГУТУ для Android

Приложение для студентов ВСГУТУ: расписание, оценки из кабинета, заметки к парам с фото, друзья, уведомления.
Сайт: https://my-esstu.online/esstu/site

Последняя версия: [Releases](../../releases/latest). Приложение само предлагает обновиться, когда выходит новый релиз.

## Сборка

Нужны JDK 17 и Android SDK 35.

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.
